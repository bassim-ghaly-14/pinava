How I Build

A repeatable process for turning requirements into maintainable products — and the principles that keep it honest.

    Understand

    Break the problem into clear requirements and constraints before any code is written.

  2. 02

    Architect

    Choose structures and patterns the codebase can grow with — not just ones that work today.

  3. 03

    Build

About

I taught myself frontend development by building real projects rather than collecting tutorials. Small decisions in state, layout, and interaction determine whether a product feels solid — so I treat them with care.

I care about scalable architecture and careful execution: predictable data flow, accessible interfaces, and designs implemented exactly as intended. Every project in this portfolio was built end to end — from the first commit to deployment — which is how I prefer to learn and work.

  • Self-taught through hands-on project building
  • Clean, maintainable, scalable code

  • Continuous learning and adaptability
